# Security policy

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue.

- Email **security@rotorlab.app**, or
- use GitHub's private vulnerability reporting: on this repository, open the **Security** tab and choose **Report a vulnerability**.

Tell us what you found, how to reproduce it, and what an attacker could do with it. We will acknowledge your report, keep you informed while we look into it, and credit you when a fix is released if you would like.

## Scope

This repository holds example code and copies of RotorLab's published API documents. Reports about the examples themselves (for example, a webhook signature check that could be bypassed) are in scope here. Reports about the RotorLab service or its API go to the same address.

## Keys and secrets

Never paste a real API key, device credential or webhook secret into an issue, pull request or discussion. If you have exposed one, revoke it in RotorLab under Organization, Integrations, and create a new one.
