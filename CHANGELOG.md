# Changelog

## 1.0.0 (2026-11-15)

First release.

- Python examples (standard library, Python 3.8 or later): check a key, list the aircraft register, read one aircraft's record, list pilots and their currency, list flights, record a flight, attach a flight log, and analyze a build.
- curl one-liners for the same calls.
- A webhook receiver that verifies RotorLab's signature.
- Setup for connecting an AI assistant to RotorLab's read-only MCP endpoint, with a small client for checking a key.
- Copies of the published OpenAPI document and Postman collection.
- Offline tests for the examples.
